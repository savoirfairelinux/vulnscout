# Supporting Tasks

These tasks support the full pipeline rather than forming additional phases.
Use them to open the interface, configure providers and container settings,
or deliberately remove obsolete data.

```{toctree}
:maxdepth: 1

cli-web-interface
cli-configuration
cli-data-maintenance
```

For navigation and screen-specific controls, see
[Interactive Mode](interactive-mode.md). For progress, cancellation, and failed
jobs, see [Operation Queue](web-operation-queue.md).

Data-maintenance commands are global, not restricted by the active project or
variant. Review their deletion plans before confirming cleanup.
