# Import

Start with an SBOM generated by your build system and any existing vulnerability
findings or VEX documents. Import them into a named **project** and **variant**,
and keep that scope consistent throughout the pipeline.

**Result:** a package inventory and any findings or assessments supplied by the
input documents. Import alone does not request additional vulnerability scans
or a complete metadata refresh.

```{toctree}
:maxdepth: 1

cli-inputs
```

Use [Getting Started](getting-started.md) for the first import or
[Bundled Examples](examples.md) for alternative datasets. The same inputs can
be uploaded through [Settings](web-settings.md).
Import companion SBOM documents together so cross-document relationships resolve.

For build-system integration, see [Yocto Integration](yocto-integration.md)
and [Zephyr Integration](zephyr-integration.md). VulnScout consumes their generated
SBOMs rather than replacing SBOM generation.

Continue with [Enrich](workflow-enrich.md) to discover additional findings and
update their metadata.
